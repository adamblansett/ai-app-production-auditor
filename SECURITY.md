# Security Policy

## Reporting Security Issues

Security is a primary concern for the AI App Production Auditor project.

If you believe you have discovered a vulnerability in the tool itself or in its rule evaluation engine, please do not open a public issue.

Instead, please report security concerns directly to:

- **Contact:** Adam Blansett
- **Email:** adam.blansett@gmail.com
- **Website:** [https://adamblansett.com](https://adamblansett.com)

Please provide:

1. A description of the vulnerability.
2. Steps to reproduce or a minimal proof of concept.
3. Potential impact.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.

## Privacy and Data Handling

The core AI App Production Auditor:

- Runs completely locally and offline.
- Never sends source code, file contents, or reports over the network.
- Redacts all potential secrets in all output formats (terminal, Markdown, JSON).
- Does not require third-party cloud services or API keys.
